## 4. Naya UI/animation (tumhari video ke hisaab se)

Video ("Dashboard V14", framer-motion code) se jo cheezein nikaali:

| Effect | Kaise banega |
|---|---|
| **Skeleton shimmer -> content aate hi staggered fade-up** (greeting, cards, chart) | `motion` `variants` + `staggerChildren: 0.06`, skeleton = CSS shimmer (`transform` based) |
| **Top pill navigation, active pill slide karta hai** (Overview / Manage / Program ...) | `motion` shared `layoutId="nav-pill"` |
| **Page switch pe content crossfade + halka slide** | `AnimatePresence mode="wait"` + route template (`app/(app)/template.tsx`) |
| **Cards pe hover lift** (`whileHover={{ y: -2 }}`) + glass-card (border + soft bg) | `motion.div` |
| **Numbers count-up** (balance, points) | `useMotionValue` + `animate()` |
| **Bars / charts grow-in** | recharts `isAnimationActive` ya motion `scaleY` |
| **Light <-> Dark toggle, circle reveal** (aakhri frames) | View Transitions API `document.startViewTransition` + `clip-path: circle()` |
| Orange gradient hero cards | `accent` se halka gradient, sirf 1-2 cards pe |

**Dashboard ke liye mapping:**
- Left icon rail (collapsible) ya top pill nav (video jaisa) â€” dono mein se ek chuno (neeche sawal).
- Overview page (naya landing): "Good morning, <name>" greeting + stat cards (Open, Pending, Closed today, Avg first reply [needs backend]) + conversations/day chart + "Recent conversations" list.
- Inbox (3-pane) wahi spec jo `DASHBOARD-REDESIGN.md` mein hai, lekin entry/exit animations upar wali table se.
- Har list/card pe skeleton, har page pe loading/empty/error.
- `MotionConfig reducedMotion="user"` (reduce-motion pe sab band).
