## 3. Motion spec (library: `motion/react`)

| Effect | Prototype | Implementation |
|---|---|---|
| Boot skeleton -> content | shimmer ~0.9s | route `loading.tsx` + per-page skeleton (CSS `@keyframes` shimmer on `transform`/`background-position`), content swap on data ready (min 300ms jab data fast aaye taake flash na ho) |
| Staggered entrance | `up` 0.65s, blur 8px -> 0, delay `i*70ms` | `variants={{hidden:{opacity:0,y:14,filter:'blur(8px)'},show:{opacity:1,y:0,filter:'blur(0px)'}}}`, parent `staggerChildren:0.07`, ease `[0.2,0.7,0.2,1]`, 0.65s |
| Page transition | out: opacity 0 + blur 8 + y 6 (150ms), then in | `app/(app)/template.tsx` with `AnimatePresence mode="wait"` keyed by pathname (exit 150ms, enter = stagger above) |
| Count-up numbers | 0 -> n in 1.1s cubic-out | `useMotionValue` + `animate(mv, n, {duration:1.1, ease:'easeOut'})`, render `useTransform(round)` |
| Progress bar fill | width 0 -> %, 1.2s | `motion.i animate={{width}}` delay .3 |
| Card hover | translateY -3px + shadow | `whileHover={{y:-3}}`, shadow `0 10px 28px rgba(0,0,0,.08)` (hero: `0 14px 34px rgba(240,86,29,.35)`) |
| Button hover | scale 1.04 | `whileHover={{scale:1.04}}`; send button: `scale 1.08 rotate -8deg` |
| New chat bubble | `up` 0.4s | `motion.div initial/animate` |
| Row hover | bg `--soft` 200ms | CSS |
| Theme switch | circle reveal 650ms from click point | util below |

**Theme util (`src/lib/theme.ts`):**
```ts
export function setTheme(t: 'light'|'dark', e?: MouseEvent) {
  const apply = () => { document.documentElement.dataset.theme = t; localStorage.setItem('theme', t); };
  const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
  if (!('startViewTransition' in document) || reduce) return apply();
  const x = e?.clientX ?? innerWidth/2, y = e?.clientY ?? 0;
  const r = Math.hypot(Math.max(x, innerWidth-x), Math.max(y, innerHeight-y));
  (document as any).startViewTransition(apply).ready.then(() =>
    document.documentElement.animate(
      { clipPath: [`circle(0 at ${x}px ${y}px)`, `circle(${r}px at ${x}px ${y}px)`] },
      { duration: 650, easing: 'ease-in-out', pseudoElement: '::view-transition-new(root)' }));
}
```
CSS: `::view-transition-old(root), ::view-transition-new(root){animation:none;mix-blend-mode:normal}`.
No-flash: root layout mein chhota inline script jo `localStorage.theme` se `data-theme` pehle hi set kare (default `light`).

## 4. Pages aur real data

### Overview (`/`)
- Greeting `Good morning/afternoon/evening, {first name}` (time-of-day se).
- **Hero (orange):** "Open chats" = count of conversations `status=open` (loop `nextCursor`, cap 500, ya sirf pehla page + "50+"); progress bar = closed today / (open + closed today). Button -> Inbox.
- **Right card:** Team (members list `GET /v1/members` â€” API sirf `userId, role` deti hai; naam/online tab tak nahi jab tak backend add na ho; abhi role badges + count). Role agent ko ye card nahi (403).
- **Stat cards (sirf real):** Open, Pending, Closed today (client count from list). "Avg first reply" Tier B (analytics endpoint) â€” tab tak card hide.
- **Recent conversations:** top 5 from `GET /v1/conversations?limit=5` (name `visitor.name ?? email ?? "Visitor xxxx"`, preview needs last message: abhi list mein nahi, to subject/"New conversation"; baad mein backend `lastMessage` add).
- **Widget card:** `GET /v1/widget/settings` + api-keys `lastUsedAt` -> "Widget live / not installed yet" + Copy install snippet.
