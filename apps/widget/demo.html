This is a stand-in host page. The LiveChat widget floats in the corner.

Tip: append ?key=pk_… to this page's URL to auto-load, or reload after minting a key in the dashboard.

How to try it

  1. Open the dashboard at http://localhost:3000 and sign up.
  2. Go to API Keys, mint a key, copy the pk_… value.
  3. Paste it above (or in the URL) and click Load widget.
  4. Chat as a visitor here, and reply as an agent in the dashboard inbox.
