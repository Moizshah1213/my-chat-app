## 4. Kya kaise kiya — techniques summary

1. **Bug diagnosis:** codebase-wide regex search (`search_codebase`) se saare
   `recordAuditFor` call sites nikale; `read_files` se controller/service padha;
   transaction boundary samjha → root cause: audit insert pre-commit = FK violation.
2. **Fix convention:** controller-level post-commit audit (service transaction
   return hone ke baad `void recordAuditFor(...)`) — matches existing pattern in
   `api-keys`, `widget-settings`, `workspaces` controllers.
3. **Validation strategy:** typecheck (tsc --noEmit) → targeted suites (auth,
   settings) → full matrix individually (chained scripts timeout ki wajah se).
4. **Background process management (Windows):** `Start-Process cmd '/c pnpm dev > log 2>&1' -WindowStyle Hidden`
   — 30s command timeout se bachne ke liye long-running installs/dev-servers
   background mein, phir log tail + `Invoke-WebRequest` se readiness check.
5. **Service discovery:** `Get-NetTCPConnection -State Listen` (kaunse ports
   already busy), `Get-CimInstance Win32_Process` (kaunsa process kaunsa hai),
   `Get-Command` (tools installed ya nahi).
6. **Process hygiene:** purane API process (pre-fix code) ko kill karke fresh
   restart — warna fix live test mein dikhta nahi.
